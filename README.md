## About The Project
This is a desktop program to manage your phone book and contacts easily. It is built using Java and Java Swing for the user interface. You can save names, phone numbers, and other details in one place.

**Loyalixa** shares this project to help students learn how to build desktop applications with graphic interfaces (GUI) in Java.

## Features
* **Add Contacts:** Save new people to your list.
* **Search Contacts:** Look for specific contacts quickly.
* **Update and Delete:** Change contact information or remove old ones.
* **Clear Screen:** Quickly clean the input boxes using the broom button.
* **Easy Design:** A simple and clear screen with nice icons.

## Built With
* **Java** - The main programming language.
* **Java Swing** - Used to make the buttons, text boxes, and screens.
* **NetBeans** - The project is structured to work easily with the NetBeans IDE.

## Getting Started

### What You Need
* Java Development Kit (JDK) installed on your computer.
* A Java program editor (IDE) like NetBeans, Eclipse, or IntelliJ IDEA.

### How to Run
1. Download or copy the project files to your computer.
2. Open your Java IDE (NetBeans is recommended for this project).
3. Select `File` -> `Open Project` and choose the `Contacts` folder.
4. Right-click on the project and select `Run`, or run the main file named `MainFrame.java` to start the app.

## Project Structure
* `src/contacts/MainFrame.java`: The file that contains the main screen design and button actions.
* `src/contacts/Client.java`: The code that describes the contact data.
* `src/Recs/`: A folder containing all the pictures and icons used in the application.
