# Contacts Management Project

This is a desktop program to help you save and manage your contacts. It has a simple user interface and saves your data locally.

## Main Features
*   **Add New Contacts:** You can easily add new people to your list.
*   **Delete Contacts:** You can remove contacts you do not need anymore.
*   **Contact Details:** You can save many details, like phone numbers, emails, addresses, and ID numbers.
*   **Save Data:** The program saves your contacts in a safe file, so you do not lose your information when you close the app.

## Tools Used
*   **Java:** The main programming language.
*   **Java Swing:** Used to make the screens, windows, and buttons.
*   **NetBeans:** The project is set up to work very well with the NetBeans IDE.

## How to Run the Project
1.  Open your Java code editor (like NetBeans, Eclipse, or IntelliJ).
2.  Open the `Contacts` project folder.
3.  Go to the `src/contacts/` folder to find the main code.
4.  Run the `MainFrame.java` file to start the program.
